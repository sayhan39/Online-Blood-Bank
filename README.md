# 🩸 Online Blood Bank Management System

## Project Description

The **Online Blood Bank Management System** is a basic, open-source web application designed to manage blood donor information and blood group availability within a digital platform. Developed as a **Web Laboratory** project, it is built around fundamental **CRUD (Create, Read, Update, Delete)** operations.

This system is intended to provide a simple, functional backend for tracking essential blood bank data using a straightforward PHP and database structure.

***

## Key Features

The system offers core functionality expected of a basic data management application:

* **User/Donor Management:** Functionality to register new donors and manage existing user records.
* **Blood Availability Check:** Users can view the current availability status of different blood groups.
* **Front-Page Interface:** A primary landing page to introduce the system and guide navigation.
* **Informational Section:** An dedicated section (`/About`) providing details about the project or blood donation.
* **CRUD Operations:** Full data manipulation capabilities for managing records stored in the database.

***

## Technology Stack

The project is developed using the following core web technologies:

* **Backend:** **PHP** (Primary server-side scripting language).
* **Database:** Likely **MySQL** (Required for the CRUD functionality).
* **Frontend:** **HTML5** and **CSS** for structure and styling.
